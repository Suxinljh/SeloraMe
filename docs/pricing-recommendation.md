# 量表定价建议

> 数据采集日期：2026-09-15  
> 适用：SeloraMe 现有 31 个量表

---

## 一、定价依据的三个维度

**不按题数定。** 市场数据不支持题量与价格相关：

| 量表            | 题量 | 价格    |
| ------------- | -- | ----- |
| 壹心理 情商测试（专业版） | 33 | ¥9.9  |
| 壹心理 抑郁测试（专业版） | 9  | ¥19.9 |
| 壹心理 MBTI      | 93 | ¥39.9 |

9 题的抑郁测试和 33 题的情商测试差了一倍价格。用户买的不是题目数量，是**结论的可信度与可行动性**。

**也不按边际成本定。** 自动化报告的边际成本趋近于 0，按成本定价只会让价格趋近于 0。

应该按这三条排序：

1. **量表权威性** —— 有无国内常模、有无信效度文献。SCL-90、EPQ 这类有常模的比娱乐化测评值钱。
2. **结果的可行动性** —— 能指导一个具体决策的比只给类型的值钱。「高考该报什么专业」有明确决策价值，「你是 INFP」只有认知价值。
3. **场景的付费动机** —— 升学、求职、亲密关系是三个高动机场景，用户在这些场景里更愿意付费。

**读出三件事：**

- **免费层的量级远大于付费层。** 免费量表最多 405.8 万次，付费量表最高 80.2 万次。免费是获客手段，不是损失。
- 8 元档也存在，但多用于短小的趣味型测评，测试人数明显偏低（千级）。

同方向的拾棠心理测试（微信小程序）：基础结果免费，深度报告 ¥4.88–12.9。

### 官方与公立定价（重要锚点）

- **广西医保局 2025 年 12 号文**：精神科 A 类量表测查（含焦虑自评、抑郁自评、汉密尔顿焦虑/抑郁等）**22.1 / 24.8 / 27.6 元每种**（按医院等级），电脑自测加收 10 元；B 类量表 34 元档。
- **北京市卫健委「暖翼」小程序**：约 52 个量表，全部免费。

这条很关键：**临床量表由医保定价时，也只是 22–27.6 元，而且包含专业人员施测与解读**。纯自动化报告的定价超过 ¥29.9，在心理量表这个品类里缺少依据。MBTI 是唯一例外，因为它卖的是品牌而非量表本身。

## 三、版权边界（决定哪些"能"收费）

| 量表                                       | 授权状态                                                                | 可否收费     |
| ---------------------------------------- | ------------------------------------------------------------------- | -------- |
| PHQ-9 / GAD-7                            | 公共领域。版权方 Pfizer 明确「无需许可，可复制、翻译、展示、分发」；国内渠道明确标注「非商用与商用领域使用均无需缴纳授权费用」 | ✅ 可以     |
| 霍兰德 RIASEC                               | 理论公开，六类型模型通用                                                        | ✅ 基本可以   |
| MBTI                                     | 「MBTI」是 The Myers-Briggs Company 的注册商标，商用需授权                        | ⚠️ 有商标风险 |
| SCL-90                                   | 版权归 Derogatis，严格说商用需授权                                              | ⚠️ 需核实   |
| BDI-II / GHQ-12 / SF-12 / EQ-5D / WEMWBS | 必须购买授权，题目不得复制                                                       | ❌ 本项目未使用 |

**MBTI 是最矛盾的量表**：它是最好卖的（壹心理 ¥39.9 卖到 80 万单），但也是商标风险最高的。三条路选一条——改名（如「16 型人格倾向测评」）、取得授权、或放免费做引流。

## 四、对 31 个量表的具体建议

### 第 1 类：免费（4 个）

`phq-9`、`gad`、`mental-self-check`、`college-mental`

公共领域 + 筛查属性。给筛查设付费墙在伦理上说不过去，且这四个是最大的流量入口（参照壹心理 405 万 vs 48 万的差距）。**放在首页推荐位做引流。**

### 第 2 类：¥9.9（8 个）

`eq`、`internal-friction`、`frustration`、`adolescent-temperament`、`learning-style`、`study-habit`、`time-management`、`msmt`

短、无临床属性、轻度自我了解。对应壹心理 8 元档与倍塔塞司专业版。

### 第 3 类：¥19.9（11 个）

`disc`、`epq`、`epq-child`、`attachment`、`love-style`、`holland`、`career-aptitude`、`aq`、`tcm-constitution`、`subject-interest`、`test-anxiety`

市场最密集价位。人格、依恋、职业兴趣都属于「有明确行动价值」的类型。

### 第 4 类：¥29.9–39.9（2 个）

`mbti`、`major-choice`

- `major-choice`（高考专业选择）：**决策价值最高**，家长付费意愿强，可直接对标倍塔塞司高中生职业倾向臻享版 ¥29.9。
- `mbti`：对标壹心理 ¥39.9，但**必须先把商标问题解决**；未解决前建议放免费。

### 第 5 类：建议免费或仅收成本价（6 个）

`scl-90`、`mssmhs`、`mhrsp`、`ybocs`、`adolescent-mental`、`wangjisheng`

理由：临床属性强，收费容易被质疑「拿筛查赚钱」；MSSMHS / MHRSP / 儿少心理面向学生，使用者多为家长与学校；且医保给同类量表定价仅 22–27.6 元（还含人工解读）。

## 五、商业化机制建议

1. **基础结果免费 + 深度报告付费**（拾棠模式）。最适合小程序：先让用户看到类型与总分，维度明细、行动建议、历史对比放在付费报告里。转化路径最短。
2. **三档 + 划线原价**（倍塔塞司模式）。免费版（类型/总分）→ 专业版（维度+建议）→ 臻享版（+人工解读）。划线原价能显著提升专业版的转化率。
3. **首页推荐位必须放免费的**。¥39.9 放在首屏会把新用户挡在门外。
4. **不要一上来全站收费**。免费量表的测试量级比付费高 5–10 倍，免费是获客手段。
